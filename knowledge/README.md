# Method library

Short method cards written in our own words. Each card names the agents it guides (`agents:`) and the public
work it summarises (`source:`). Cards are **guidance on how to work, never evidence about a market**: they are
added to an agent's instructions, logged by id in `decision_log.json` (`knowledge_cards`), and nothing from them
can enter the Evidence Ledger or count at a gate. Add a card by adding a file; keep each under ~150 words.
